# By reading this page, you are mining bitcoins (Quartz) — archival copy

A self-hosted, archival copy of the Quartz article "By reading this page, you
are mining bitcoins" (December 2013), originally published at
`qz.com/154877/by-reading-this-page-you-are-mining-bitcoins/`. Quartz's
archives were gutted after the site changed hands; this copy was reconstructed
from the Internet Archive's Wayback Machine (June 2014 capture, original
design) so the work remains readable.

by Quartz.

inert. The article and illustrations are intact.
